# Contributing

This project is currently **not accepting external contributions**. The skill is authored and maintained by the NVIDIA Nemotron Speech team and follows the NVIDIA IP-review process for outbound agent skills.

## How to report problems

- **Bugs or incorrect content** in `SKILL.md` or any reference file: open an [issue](../../issues) on this repository
- **Feature requests** (a new reference chapter, a missing workflow): open an [issue](../../issues) describing the use case
- **Security vulnerabilities**: see [`SECURITY.md`](SECURITY.md) — do *not* file these via public issues
